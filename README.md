# 当たり前更新プログラム v004 — 全42日

## コンセプト

身体反応・予測・小さな実体験を観察しながら、「許可 → 選択 → 実現」を段階的に練習するプログラムです。心理療法や医学的な診断ではなく、日々の自己観察と行動実験を支援するツールです。14日間で習慣や心理状態の改善を保証するものではありません。

| フェーズ | 期間 | 内容 |
|---|---|---|
| 1 許可を育てる | 14日 | 欲する・受け取る・持つ・使う・返すを分ける |
| 2 選択を通す | 14日 | 欲しい・買う・待つ・断るを自分で選ぶ |
| 3 実現を始める | 14日 | 望みを具体化し、小さく行動し、続ける／変える／待つ／手放すを選ぶ |

「14日」はタスクの単位です。連続した14暦日で終える必要はありません。行動が負担になる日は、考えたことや保留したことを記録するだけでもOKです。

## v004の主な仕様

- Phase 1〜3を一本化。Phase 3は前の2フェーズの完了後に進めます。
- 1日につき4つの文章の0〜10自己評価、身体反応、感情の候補、実践前の予想、実際の結果、気づきを記録。
- Phase 3は「今日の取り組み方」「次の小さな一歩（保留もOK）」も記録。
- 進捗・フェーズごとの開始／終了比較・日別のスコア推移を確認。
- 入力途中の内容も同じブラウザ内に自動一時保存。［DAYを保存］を押すと記録が確定。
- 全フェーズまとめてJSONバックアップ、CSV、ChatGPT用テキストに出力。
- 旧v003のデータを同じサイト内で自動移行。v003原本キーは削除しません。
- インポート時は「統合（既存記録優先）」が標準。全置き換えは明示的に選ぶ必要があります。
- PWA対応。インターネット接続があれば最新コンテンツを優先し、キャッシュがあればオフラインでも利用可能です。

## GitHub Pages公開手順

1. 新しいリポジトリを作るか、**今のv003と同じリポジトリ**を開きます。
2. ZIPを解凍し、`index.html` `app.js` `program.js` `sw.js` `manifest.webmanifest` `README.md` と2つのPNGアイコンをリポジトリ直下へアップロード／上書きします。
3. 新規リポジトリなら GitHub → Settings → Pages → Build and deployment → Deploy from a branch → `main` / `/(root)` を選びます。
4. 公開URLをスマートフォンのChromeなどで開きます。アプリの右上付近に **v004 · 42 DAYS** と表示されたことを確認してください。
5. 旧画面が出る場合はインターネット接続を確認し、ページを再読み込みしてください。

**同じURLが重要です。** `localStorage` はオリジンごとに分かれるため、GitHub Pagesのリポジトリ名やドメインを変更すると旧データを自動参照できません。URLを変えた場合は旧アプリからJSONを書き出し、新アプリで読み込んでください。

## v003からの移行

- v004は初回起動時に `atarimae_update_v003` という旧キーを読み、 `atarimae_update_v004` という**新しいキーにコピー**します。
- 旧キーの内容は破壊しません。
- 既存のPhase 1/2の記録、開始・終了時の評価、振り返りはそのまま移行されます。
- Phase 2が完了していれば、**Phase 3の開始時チェック**から始まります。
- 旧データを別サイトから移すときは「データ」→「復元・移行」でバックアップJSONを読み込んでください。

## 個人バックアップについて

別途提供する個人用28日分の復元JSONは、このGitHub用ZIPに**含まれていません**。公開リポジトリにアップロードしないでください。

取り込むときは、公開URLを開き「データ」→「復元・移行」からJSONを選択します。**まず統合モードで取り込み**、各フェーズの記録数と最終評価がそろっているか確認してください。統合では、既に存在する同日の記録より、手元の記録を優先します。

## データの安全性

- ブラウザの `localStorage` に保存します。サーバーには自動送信しません。
- 別端末、別ブラウザ、別ドメインでは通常自動同期されません。
- ブラウザデータ削除や端末故障に備えて、数日おきに**データ → JSONバックアップ**を保存してください。
- v004は進捗が増えていてバックアップが古いとき、ホーム画面に推奨を表示します。
- 同じ端末の `localStorage` だけでは万全な保全になりません。別の安全な場所にJSONバックアップを保管してください。
- 個人用バックアップを第三者と共有すると、記録内の個人的な内容が見えます。
